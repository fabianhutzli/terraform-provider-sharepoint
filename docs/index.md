# SharePoint Provider

The SharePoint provider manages Microsoft SharePoint Online: sites and hub sites, lists, views and columns, permission levels and site groups, site scripts and site designs, themes, SPFx solutions and extensions, and tenant-wide settings.

## Requirements

The provider does not call the SharePoint or Graph REST APIs itself. It runs the [CLI for Microsoft 365](https://pnp.github.io/cli-microsoft365/) (`m365`) for every operation, so the `m365` CLI must be installed and on `PATH` on the machine running Terraform:

```sh
npm install -g @pnp/cli-microsoft365
```

## Authentication

The provider signs in unattended (app-only) with an Entra ID app registration and a certificate:

1. Register an application in Entra ID and grant it the SharePoint application permissions your configuration needs, for example `Sites.FullControl.All`.
2. Create a certificate and upload its public key to the app registration.
3. Configure the provider with the app's client ID, your tenant, and the PFX certificate, either as a file path or inline as base64.

All attributes can also be set through environment variables: `SHAREPOINT_CLIENT_ID`, `SHAREPOINT_TENANT_ID`, `SHAREPOINT_CERTIFICATE_PATH`, `SHAREPOINT_CERTIFICATE_BASE64` and `SHAREPOINT_CERTIFICATE_PASSWORD`.

~> **Security note:** the certificate password is passed to the `m365` CLI as a `--password` process argument during the one-time login, because the CLI has no environment-variable or stdin alternative. For the lifetime of that login process, other local users on the same machine can see it in the process list. Run Terraform on a single-user machine, such as a dedicated CI runner, if that matters in your environment.

## Example Usage

```terraform
terraform {
  required_providers {
    sharepoint = {
      source = "fabianhutzli/sharepoint"
    }
  }
}

# App-only authentication with a certificate. Every attribute can instead be
# supplied through the matching SHAREPOINT_* environment variable.
provider "sharepoint" {
  client_id            = "00000000-0000-0000-0000-000000000000"
  tenant_id            = "contoso.onmicrosoft.com"
  certificate_path     = "/path/to/sharepoint-app.pfx"
  certificate_password = var.certificate_password
}

variable "certificate_password" {
  type      = string
  sensitive = true
}
```

### Optional

- `certificate_base64` (String, Sensitive) Base64-encoded PFX certificate. Use this instead of certificate_path for CI/CD pipelines. Can also be set via SHAREPOINT_CERTIFICATE_BASE64.
- `certificate_password` (String, Sensitive) Password for the PFX certificate. Leave unset if the certificate has no password. Can also be set via SHAREPOINT_CERTIFICATE_PASSWORD.
- `certificate_path` (String) Absolute path to a PFX certificate file on the machine running Terraform. Mutually exclusive with certificate_base64. Can also be set via SHAREPOINT_CERTIFICATE_PATH.
- `client_id` (String) Azure AD application (client) ID. Can also be set via SHAREPOINT_CLIENT_ID.
- `tenant_id` (String) Azure AD tenant ID (GUID) or domain, e.g. contoso.onmicrosoft.com. Can also be set via SHAREPOINT_TENANT_ID.
